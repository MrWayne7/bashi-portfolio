Preguntas frecuentes

Todas las preguntas

¿Cuánto tarda una página?

Una landing toma alrededor de una semana; un sitio de varias páginas, de dos a cuatro.

¿Puedo cambiar los textos yo mismo?

Sí, si el proyecto incluye panel. También ofrezco mantenimiento mensual.

¿Necesito tener fotos?

No. Puedo hacer la sesión de fotos y video para el sitio.
